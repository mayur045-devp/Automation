## 2. Section Classification Breakdown

### Category A: Fully Strapi-Driven Sections
1. **Discovered Fields in `SchemaExplorer.svelte`**: Populated entirely by introspecting the live Strapi GraphQL endpoint. If a new content-type is created in Strapi Admin, it appears automatically upon clicking "Reconnect".
2. **Result Cards in `DataViewer.svelte`**: Consumes raw data returned by `client.request()` and dynamically creates key-value rows for each record returned by the database.

### Category B: Automation Service-Driven Sections
1. **Field Mapping Preview in `ImportPage.svelte`**: Shows the parsed values (`Title`, `slug`, `description`, `content`) generated by Mammoth and Google Gemini AI from the uploaded `.docx` file.
2. **Draft Confirmation in `ImportPage.svelte`**: Shows the persistent Strapi `documentId` and verification check returned after draft creation.

### Category C: Fully Hardcoded / Static Sections
1. **Quick Setup Guide**: Explains the 5 steps needed to configure Strapi GraphQL.
2. **Navigation Bar and Brand Headers**: Brand titles, logos, and links.
