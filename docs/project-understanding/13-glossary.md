# 13 — Glossary of Project-Specific Terms & Concepts

### 1. `documentId` (Strapi 5)
A stable, persistent, string-based unique identifier generated by Strapi 5 for every content entry (e.g., `"v7ptey5dt0h1rydhnre4u2b4"`). Unlike auto-incrementing integer IDs (`id`), `documentId` remains constant across draft and published versions of the same entry.

### 2. Draft & Publish
A content workflow mode built into Strapi 5. When enabled, records can exist in an unpublished **Draft** state (`publishedAt: null`). All automated Word imports in this system are strictly marked as drafts to prevent accidental publishing.

### 3. Shadow CRUD (`@strapi/plugin-graphql`)
A feature of the Strapi GraphQL plugin that automatically generates queries, mutations, input types, and resolvers for every collection and single type defined in Strapi, without requiring manual GraphQL schema writing.

### 4. Svelte 5 Runes
The reactivity primitive introduced in Svelte 5 (`$state()`, `$derived()`, `$effect()`, `$props()`). Replaces the older Svelte 4 compiler-based reactivity (`let count = 0`, `$: double = count * 2`).

### 5. Mammoth (`mammoth`)
A specialized Node.js library that reads `.docx` files by parsing raw OpenXML markup into semantic HTML (`<h1>`–`<h6>`, `<p>`, `<table>`, `<ul>`), avoiding formatting clutter like inline font styles and margin spans.

### 6. Zod (`zod`)
A TypeScript-first schema declaration and data validation library. In `word-to-strapi-service`, Zod verifies that extracted payloads conform strictly to Strapi's schema limits before making network requests.

### 7. Prompt Injection Defense
Security constraints implemented in `mapper.ts` that instruct the LLM to treat document text as untrusted raw data rather than executable instructions, preventing malicious Word documents from hijacking CMS operations.

### 8. Introspection (`__schema`)
A native capability of GraphQL that allows clients to query the schema itself at runtime to discover available types, queries, mutations, and field definitions.

### 9. Idempotency Check
An operation guarantee in `word-to-strapi-service` that queries Strapi by title equality before creating a draft, preventing duplicate records if an editor clicks the import button multiple times.

### 10. Re-fetch Verification
A quality assurance step executed by `strapiClient.ts` immediately after draft creation: the newly created entry is fetched back from Strapi and compared field-by-field against the approved payload to guarantee data fidelity.
